# BetterMapMaker

An online brawl stars map maker with support for exporting to a game readable format

## Features:
- Saving as CSV and PNG
- Support for most themes and gamemodes (currently up to v59, old themes may be incomplete)
- Building helpers, such as mirror, templates and undo/redo
- Loading (from CSV)
- Support for out of bounds areas (used ingame on 5v5 maps, but works elsewhere)
- Error checking
